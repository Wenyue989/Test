# Request for Proposal (RFP)
### Wireless Network Infrastructure Deployment

---

##  1. Introduction

This Request for Proposal (RFP) seeks qualified vendors to design, install, and support a secure wireless network infrastructure for our organization. The purpose of this project is to improve network performance, enhance coverage, and implement modern security and network management capabilities.

---

##  2. Project Objectives

- Provide stable and high-performance wireless connectivity throughout the building.
- Support the latest Wi-Fi networking standards.
- Ensure robust cybersecurity configurations and secure authentication.
- Deploy a scalable and manageable wireless system suitable for future needs.
- Provide long-term support, maintenance, and system monitoring.

---

## 3. Scope of Work

| **Task Area** | **Description** |
|:----------:|:------------|
|  Site Survey | Perform a wireless spectrum analysis and determine optimal access point placement. |
|  Installation & Configuration | Deploy and configure wireless access points, SSIDs, VLANs, authentication, and security policies. |
|  Network Integration | Ensure seamless integration with existing wired network infrastructure, DHCP, firewall, and switching systems. |
|  Maintenance & Support | Provide ongoing technical support, troubleshooting, firmware upgrades, and system optimization. |

---

## 4. Technical Requirements

- Wireless standard: **Wi-Fi 6 (802.11ax)** or newer.
- Full Wi-Fi coverage throughout:
  - Offices
  - Meeting rooms
  - Public areas
- Network Security Requirements:
  - WPA3 encryption
  - MAC address filtering
  - Guest network isolation
  - Optional 802.1X authentication
- Capacity for high device density (Minimum: **100 clients simultaneously**)
- Centralized network monitoring dashboard
- Compatibility with existing switching and firewall systems

---

## 5. Deliverables

- Wireless site survey report
- Final network design and topology map
- Access point placement blueprint
- Configuration documentation (SSID, VLANs, security policies)
- Performance testing and validation report
- Training materials for IT staff
- Maintenance & support plan details
